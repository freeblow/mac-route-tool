SRM 网络助手 · 便携版（目标电脑不用装 .NET）

怎么用
  1. 把整个文件夹一起拷到目标电脑（U 盘、共享盘都行），别只拷“SRM 网络助手.exe”一个文件。
  2. 双击「SRM 网络助手.exe」。
  3. Windows 问“是否允许此应用对你的设备进行更改”时点「是」——改路由、调网卡优先级、禁用网卡都要管理员权限。

为什么不用装 .NET
  runtime\ 里自带了一份 .NET 8 运行时，启动器把程序指到这份自带运行时上，
  所以目标电脑装没装 .NET 都无所谓，也不会去动系统里已有的 .NET。

文件夹里都有什么
  SRM 网络助手.exe   入口，双击它（带程序图标）
  app\               程序本体，别单独挪出去
  runtime\           自带的 .NET 8 运行时，别删、别改
  使用说明.txt        本文件

要求：Windows 10 1903 以上 / Windows 11，64 位。

卸载
  直接删掉整个文件夹即可。程序只会在 %ProgramData%\SRM\routes.json 里保存你的静态路由配置，
  想连配置一起清掉就删掉那个目录（不删也不影响，删了只是要重新配一遍）。

想看更多说明
  见源码目录里的 README.txt：网卡优先级、多网卡共存、IP 检测、LocalSend/投屏发现、排错，都有写。
  运行日志在 C:\ProgramData\SRM\srm.log。
