SRM 网络助手 v2.8.0（Windows 10 / 11）
静态路由 + 网卡优先级 + 多网卡共存 + 网卡启停，一个窗口全搞定。

【怎么启动】
1. 双击根目录的「SRM 网络助手」快捷方式，或双击 dist\SRM.exe。
2. Windows 弹出管理员权限提示时点“是”（写入路由、调整网卡优先级都必须有管理员权限）。
3. 窗口上方有三个标签：「静态路由」「网卡优先级」（多网卡共存的开关也在这里）、「IP 检测」（查网段里哪些 IP 空闲、哪些被占用）。
4. 界面右上角可以切换「中文 / English」：第一次启动按系统语言自动选，之后记住你的选择。

需要 .NET 8 桌面运行时（本机已安装 8.0.22，无需再装）。
如果要在别的电脑上运行，先装一次 “.NET 8 Desktop Runtime (x64)”，再复制 dist 整个文件夹过去。
不想装运行时也行，两条路：
· 手头这台电脑装好过 .NET 8 时：双击 tools\生成便携版.cmd，生成一份“便携版”整个文件夹（约 162 MB，运行时直接从本机复制，不用联网），
  把整个文件夹拷到别的电脑，双击里面的「SRM 网络助手.exe」就能用，对方不用装 .NET。
· 想只带一个文件：双击 tools\生成免安装版.cmd，生成“免安装版”（单个 SRM.exe，约 70 MB），拷过去双击就能用。
两条路的细节都在下面【自己编译 / 改界面】。

【静态路由】
· 「+ 添加路由」：目标网段支持三种写法 —— 10.40.85.0/24（整个网段）、10.40.85.7（单台主机）、default（默认路由）；
  保存时自动规范化，例如 10.40.85.99/24 会变成 10.40.85.0/24。
· 网关就是该网段的下一跳，通常填当前网卡的默认网关（列表里“网卡优先级”页能看到）。
· 出口网卡一般保持“自动”，只有多网卡需要强制指定出口时才选具体网卡。
· 状态颜色：绿色=已生效且重启后仍保留，黄色=待写入，灰色=已停用，红色=写入失败（鼠标悬停看原因）。
· 「编辑」「启用 / 停用」「删除」针对选中的那一行；双击某行也能编辑。
· 「重新同步」会按配置重写一遍持久路由；程序每 21 秒也会自动检查补写一次。
· 行尾「测试」按钮：主机路由（/32）测目标 IP，网段路由测网关 IP。对方禁 Ping 时会显示未响应，属正常现象。
· 右键任意一条路由可以复制：整条（含状态、网关、出口、备注）或只拷目标网段。
· 列表下方的「系统里其它路由（不归 SRM 管）」：把系统里已经存在、但不在 SRM 配置里的路由也列出来，
  方便对照 route print。会出现在这里的有两类：
    · 持久路由 —— 用 route -p add 或 PowerShell 的 New-NetRoute 加的（旧版 SRM.ps1 就是后一种）。
      这类条目以前藏在 NetTCPIP 持久存储里，所以老版本看不到它们；确定没用了点右侧「删除」，
      SRM 会把系统路由表、注册表、NetTCPIP 持久存储三处一起清掉。
    · 网卡静态网关 / 网卡旧配置残留 —— 「网络连接」里网卡属性填过的网关（包括已停用网卡留下的旧配置）。
      这类 SRM 不直接删，免得动坏网卡设置；按行内提示到「网络连接 → 该网卡 → 属性 → IPv4」里改。
  系统里没有这类条目时，这一块不会显示。

【网卡优先级】
· 列表按优先级从高到低排列，序号列是 Windows 的接口序号；跃点数越小越优先。
· 选中网卡后「↑ 提高优先级 / ↓ 降低优先级」会自动分配新的跃点数（IPv4 与 IPv6 同时写入），
  点一下立即生效，重启后依然保留。
· 「恢复自动跃点」把所选网卡交回 Windows 自动排序（系统默认行为）。
· 「禁用网卡 / 启用网卡」= 在“网络连接”里右键禁用/启用同一件事，禁用后网卡仍留在列表里并标记“已禁用”，
  随时可以再启用；禁用前会先弹窗确认，避免误点到正在上网的网卡。
· 列表只显示“网络连接”里能看到的网卡（WAN Miniport、内核调试等隐藏适配器不会出现，减少干扰）。
· 表格里右键可以复制：整块网卡的信息（按 Tab 分列，含 IP、网关、跃点数、型号等），或者只拷 IPv4 地址。

【多网卡共存（让多块网卡一起干活）】
多块网卡同时开着时最常见的毛病是“起了这块、那块就不好使”：几块网卡都在抢默认路由（上网出口），
或者高优先级网卡把别的网卡的流量搅乱。这个页面现在给了三个抓手：

· 「上网出口」列：绿色=正在负责上网；黄色「备用出口」=也有默认路由、正在跟别人抢出口（容易打架）；
  灰色「仅内网」=已设为不抢上网出口；「—」=没有网关，不参与上网。
· 「共存」列 = 是否允许跨网卡收发（Windows 的“弱主机模式”）。系统默认只收“目标地址属于自己”的包，
  多网卡时容易互相丢包；打开后这块网卡可以收发本机其它网卡上的流量。
· 「一键共存」：只保留一块网卡当上网出口，其余带网关的网卡改成仅内网，并让在用网卡都允许跨网卡收发。
  点之前会先列出每一步改什么，确认后才动手；列表上方出现橙色提示条时，就是它在提醒你有网卡在抢出口。
· 「设为上网出口」：让选中的网卡负责上网，其它抢默认路由的网卡自动改成仅内网。
· 「设为仅内网」：选中的网卡不再抢上网出口，但访问它自己网段里的设备（内网 NAS、虚拟机、开发板等）照常。
· 「允许跨网卡收发 / 禁止跨网卡收发」：单独开关选中网卡的弱主机模式。

说明：仅内网只是“不负责上外网”，网卡不会断、不会被禁用，本网段访问一切照旧；所有设置重启后依然有效，
想改回去随时点「设为上网出口」。

【IP 检测（网段里哪些 IP 空闲、哪些被占用）】
用途：给新设备（打印机、摄像头、开发板、虚拟机）挑一个没人用的 IP，或者查某台设备还在不在。
· 目标填在「网段或地址」框里，支持三种写法：
    · 192.168.15.0/24 —— 整个网段；左边下拉会列出本机各网卡的网段，点一下自动填进来；
    · 192.168.15.66 —— 只查这一个地址；
    · 192.168.15.1-200 —— 从 1 查到 200（终点也支持写成完整地址）。
· 点「开始检测」，每个地址给出状态：
    绿色「空闲可用」—— 没人在用，可以放心分配；
    橙色「已被占用」—— 有设备在，还会显示它的 MAC 地址（网卡硬件地址）；
    蓝色「网关 / 本机」—— 路由器网关和本机自己的地址；
    灰色「保留地址」—— 网络地址和广播地址，不能分给设备；
    灰色「查不到」—— 目标不在本机网段，Ping 又不通，无法确定（把地址改成本机网段再查就准了）。
· 判断依据：地址在本机网段时用 ARP 探测（相当于在局域网里喊一声“这个 IP 是谁的”），
  比 Ping 可靠：对方开防火墙、不响应 Ping 也照样查得出来；不在本机网段的地址只能靠 Ping。
· 「显示」可以只看「已占用」或「只看空闲」，方便在一大串地址里挑空号。
· 「导出 CSV」把结果存成表格文件，Excel 直接打开、中文不乱码。
· 复制结果：右键任意一行 →「复制地址」只拷 IP，「复制整行」把这一行按 Tab 分列拷走（粘进 Excel 正好一列一格）；
  「复制当前列表的全部行」把当前显示的所有行连表头一起拷走（先按右上角「显示」筛选再拷也行）。
  双击一行等于复制地址，选中后按 Ctrl+C 也可以（多选就拷多行）。
· 「停止」随时中断；一次最多查 2048 个地址，太大的网段请拆开查。
· 这个功能只看不写：查一遍不会改动系统里的任何设置。

【局域网里搜不到这台机器（LocalSend、投屏、打印机发现等）】
这类功能靠“向局域网喊话”（组播）互相发现，要同时满足两件事，缺一件就成了「我能搜到别人、
别人搜不到我」：
  ① 喊话要从“和对方同一个局域网”的那块网卡发出去；
  ② 别人发过来的发现包要能被这台机器的防火墙放进来。
① 多网卡机器上 Windows 只会挑一块网卡喊，挑哪块是看网卡的“跃点数”的（数越小越优先，通常挑到
  Wi-Fi）。只给喊话地址加一条路由改不了这个选择，所以 SRM 会把跃点数也一起调好。
  不想让 SRM 动系统设置（或者调了跃点数仍不管用），可以跳过这一步：直接用网卡页第四行的
  「喊一声（让对面立刻看到）」，它直接从选中的网卡把话喊出去，不看系统挑哪块网卡。
· 网卡页第三行的「让局域网能发现这台机器」：选中办公/内网网卡后点一下，一次做完这些事：
    停掉挡路的「阻止」入站规则（只是停用、没有删除，想恢复可以到防火墙里重新启用）；
    把发现端口 53317 放行到所有网络位置（TCP + UDP，专用和公用都放行）；
    把这块网卡所在网络的“位置”改成「专用」（可信网络）；
    把 224.0.0.167 的旧路由清干净（包括以前版本留下的、指向回环的残留），重新写一条只走这块网卡的；
    系统要是还挑别的网卡发喊话，就把这块网卡的跃点数调到最低（比其它网卡都小 1），调完立刻复查；
      真会把上网出口也抢过来时会自动跳过并还原，不会把网络搞断。
  每一步都会实测，最后弹窗列出：改了哪几条规则、系统现在把喊话从哪块网卡发、真发包的实测结果、
  这块网卡在不在发现组里，最后还会用 LocalSend 的身份从这块网卡主动喊一声。想还原跃点数：在「网卡优先级」页点「恢复自动跃点」。
· 「让局域网发现走这块网卡」：只给 224.0.0.167 加一条只走选中网卡的路由（不碰跃点数）。
  点完会立刻检查并如实告诉你结果；系统要是还挑别的网卡，它会提示改用上面那个「修复」按钮。
  按钮会变成「局域网发现：改回自动」，再点一次就恢复系统自动选网卡。
② Windows 防火墙按网卡所在网络的“位置”（专用 / 公用 / 域）分别套规则，而 LocalSend 安装时给自己
  加了一条「公用网络 → 阻止入站」的规则；规则里「阻止」永远优先于「放行」——所以哪怕发现端口
  53317 早就放行了，只要这块网卡被系统当成公用网络，别人发来的发现包还是会被直接丢掉：只出不进。
· 网卡页第三行的「听听看（诊断）」：在发现端口上听 10 秒，列出谁在喊话、本机自己的喊话是从哪个
  地址发出去的（源地址属于哪块网卡，喊话就是从哪块网卡出的）。只读，不改系统设置。
· 「喊一声（让对面立刻看到）」：按发现软件（LocalSend）的协议，用这台机器上 LocalSend 自己的设备名
  和证书指纹，从选中的网卡主动发一条“我在这里”。发送套接字直接绑在这块网卡的地址上，所以
  “系统挑哪块网卡”完全不影响它——系统把 Wi-Fi 排在前面也照样喊得到；点一次喊 3 声，弹窗里还会
  用网卡的发送计数证明包真的从这块网卡出去了。
· 「一直喊（每 15 秒一次）」：每 15 秒自动替你喊一次，对方列表里就能一直有这台机器；再点一下停止，
  程序关掉也会停。对面要能传文件过来，这台机器的 LocalSend 得开着。
· 按钮右边的提示随时显示「喊话出口 + 入站防火墙状态」，一眼能看出问题出在哪一半；鼠标停上去有
  详细说明（包括被哪几条规则挡住）。
· 以上都只影响这类局域网发现用的入站放行和组播，不影响上网，也不影响普通访问。
· 一直不行时看日志：每一步的原话（命令、退出码、输出、实测结果）都记在
  C:\ProgramData\SRM\srm.log（超过 256 KB 自动滚成 srm.log.1），可以直接把这个文件发给我。
· 如果都点了还是搜不到：多半是那个软件自己指定了网卡。LocalSend 可以到「设置 → 高级 → 网络接口」里
  把不想用的网卡（Wi-Fi、VMware 虚拟网卡）排除掉，然后重启它（它是启动时挑网卡的）；
  也可以在对面的 LocalSend 里手动按 IP 添加设备并加入收藏（本机地址看「地址」列，例如 10.40.81.63）
  ——收藏的设备不靠喊话也能找到。

【虚拟机网段撞车（VMware 的 VMnet1 / VMnet8）】
VMware 会自己开两块虚拟网卡：VMnet1（仅主机）和 VMnet8（NAT）。它们没有网关、不抢上网出口，
在 SRM 的「上网出口」列显示“—”，这是正常的，不用管。真正要留意的是它们的“网段”：
如果虚拟网段和真机网段撞车（比如 VMnet1 正好也是 192.168.15.0/24，和你的 Wi-Fi 一模一样），
本机和虚拟机就分不清 192.168.15.x 该走虚拟机还是真网卡，表现成“时好时坏”。
检查 / 修改办法（挑一个）：
· VMware Workstation → 编辑 → 虚拟网络编辑器（需要管理员）→ 选中 VMnet1 → 改子网 IP → 应用。
· 用仓库里的小工具，双击/右键运行即可（它会自己弹管理员，改完把新地址打印出来）：
    tools\Fix-VMnet-Subnet.ps1
  它自己找出撞车的虚拟网段，换到一个空闲网段（默认 192.168.155.0/24），
  同时改好 VMware 的 DHCP 配置并重启它的服务；先看看它准备干什么、不动系统就加 -DryRun。
  改完在虚拟机里重新获取一次 IP：虚拟机里手动填过 192.168.15.x 的，要改到新网段。

【自己编译 / 改界面】
· 用 Visual Studio 2022 打开 SRM.sln，直接 F5（项目已设置以管理员身份运行，会弹 UAC）。
· 命令行：dotnet build SRM.sln -c Release -o  /  dotnet publish src\SRM.App -c Release -o dist
· 生成“不依赖 .NET”的免安装版：双击 tools\生成免安装版.cmd（也可以右键运行 tools\Publish-Standalone.ps1）——第一次要联网下载约 90 MB 的运行时包，
  脚本会自己挑可用的下载源（连不上 nuget.org 就自动换国内镜像；公司内网镜像用 -Source 参数指定），不需要改系统的 NuGet 配置；
  之后会缓存下来，不用再下。产物在 dist-standalone\SRM.exe，约 70 MB，双击即用；
  加 -KeepFolder 参数则生成“一堆文件的文件夹”版本，启动异常时用它排查更方便。
· 生成“便携版”（本机已装好 .NET 8 时推荐这条路，全程不用联网）：双击 tools\生成便携版.cmd（也可以右键运行 tools\Build-PortableFromLocalRuntime.ps1）——
  它直接把本机的 .NET 8 运行时复制进包里，产物在 dist-portable\，约 162 MB；入口是里面的「SRM 网络助手.exe」；
  拷到别的电脑上双击即用，对方不用装 .NET。它只是给子进程设了 DOTNET_ROOT，不改目标电脑的任何系统设置。
· 改完界面想先看效果：dotnet run --project src\SRM.UiSmoke -- <输出目录>
  它会把三个标签页和对话框渲染成 PNG（中文、英文各一份，英文文件名带 -en），不会真的改动系统。
· 界面文案都在 src\SRM.Core\Localization\：StringsZhHans.cs 和 StringsEnglish.cs 是按「键」一一对照的两张表，
  代码里用 Loc.T("键") 取当前语言的文字；加新文案时两张表都要补上同一个键。
· 自检：src\SRM.Checks\bin\Release\net8.0-windows\SRM.Checks.exe（加 raw 参数可看原始数据；加 probe 6 可以试写第 6 号网卡，写入的是与当前完全相同的值，不会真的改动系统，用来确认有没有写权限）
  加 firewall-script 6 可以把「让局域网能发现这台机器」将要执行的 PowerShell 脚本原样打印出来，
  想先核对它要动什么的时候用（只是打印，不改系统）。
· 想换程序图标：把 macOS 的图标文件（.icns）放成 src\SRM.App\SRM.icns，再运行 tools\Import-IcnsIcon.ps1，
  就会重新生成 src\SRM.App\SRM.ico（10 个尺寸）和 docs\preview-icon.png —— 当前图标就是这么来的。
  也可以改 tools\New-SrmIcon.ps1 里的画法（圆角底色、那几个圆点和连线），用它重新画一个。

【排错】
· 提示“需要管理员权限”：右键 SRM.exe →“以管理员身份运行”。
· 状态一直是“待写入”：说明 route.exe 写入失败，鼠标悬停看具体错误；常见原因是网关填错或该网卡不在同一网段。
· 调整优先级失败：该网卡可能没有启用 IPv4，先在“网络连接”里确认网卡已启用。
· 别人搜不到这台机器：在网卡页选中办公网卡，点「让局域网能发现这台机器」；再看这个按钮右边的提示，
  里面那句「入站防火墙」会直接告诉你是哪一半出了问题（喊话出口不对，还是入站被规则挡住）。
· 偶尔能搜到、过一会儿又没了：对方那边是靠“喊话”刷新的，点一下「一直喊（每 15 秒一次）」最省事。

· 某块网卡从来不通：先看「上网出口」列（写着“仅内网”是故意的，不是坏了），再给它点「允许跨网卡收发」；需要它自己上网就点「设为上网出口」。
· 界面顶部的橙色提示条出现时，说明当前没有管理员权限，所有写操作都会失败。
